# Frontend

Next.js UI for the Employee Salary Management System. See the repo root
[`README.md`](../README.md) for how to run this alongside the backend, and
[`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) for how it fits together.

Bootstrapped with `create-next-app` (TypeScript, App Router, Tailwind CSS);
Zustand is added for client-side UI state (filters, pagination, form drafts).
